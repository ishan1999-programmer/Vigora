# Vigora Machine Works

A responsive informational website built from the Vigora Machine Works brochure.

## Run locally

```sh
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```sh
npm run build
npm run typecheck
```

Product, automation and contact content lives in `lib/content.ts`. Local brochure image crops are in `public/images/`.
